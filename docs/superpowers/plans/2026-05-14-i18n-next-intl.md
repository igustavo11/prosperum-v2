# i18n com next-intl — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Instalar e configurar `next-intl` para suporte a `pt` e `en` com roteamento por prefixo de URL e detecção automática via `Accept-Language`.

**Architecture:** O Next.js middleware intercepta cada request, detecta o locale via `Accept-Language` e redireciona para `/pt/...` ou `/en/...`. Todas as rotas ficam dentro de `src/app/[locale]/`. As traduções são carregadas server-side em `src/i18n/request.ts` e disponibilizadas via `NextIntlClientProvider` no layout.

**Tech Stack:** Next.js 16 (App Router), next-intl, TypeScript

### Task 3: Configurar next-intl server-side

**Files:**
- Create: `src/i18n/request.ts`

- [ ] **Step 1: Criar `src/i18n/request.ts`**

```ts
import { getRequestConfig } from 'next-intl/server'
import { routing } from '../middleware'

export default getRequestConfig(async ({ requestLocale }) => {
  let locale = await requestLocale

  if (!locale || !routing.locales.includes(locale as 'pt' | 'en')) {
    locale = routing.defaultLocale
  }

  return {
    locale,
    messages: (await import(`../messages/${locale}.json`)).default,
  }
})
```

### Task 6: Criar layout localizado

**Files:**
- Create: `src/app/[locale]/layout.tsx`
- Delete: `src/app/layout.tsx`

- [ ] **Step 1: Criar `src/app/[locale]/layout.tsx`**

```tsx
import type { Metadata } from 'next'
import { Urbanist } from 'next/font/google'
import { NextIntlClientProvider } from 'next-intl'
import { getMessages } from 'next-intl/server'
import { notFound } from 'next/navigation'
import { routing } from '../../middleware'
import '../globals.css'

const urbanist = Urbanist({
  variable: '--font-urbanist',
  subsets: ['latin'],
})

export const metadata: Metadata = {
  title: 'Prosprerum',
  description: 'Prosprerum',
}

type Props = {
  children: React.ReactNode
  params: Promise<{ locale: string }>
}

export default async function LocaleLayout({ children, params }: Props) {
  const { locale } = await params

  if (!routing.locales.includes(locale as 'pt' | 'en')) {
    notFound()
  }

  const messages = await getMessages()

  return (
    <html lang={locale} className={`${urbanist.variable} h-full antialiased`}>
      <body className="min-h-full flex flex-col">
        <NextIntlClientProvider messages={messages}>
          {children}
        </NextIntlClientProvider>
      </body>
    </html>
  )
}
```
